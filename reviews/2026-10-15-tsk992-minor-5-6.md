# tsk-992: MINOR №5 и №6 ревью повтора + review-gate

Дата: 2026-10-15. Решение оператора: «отказы гейтов не считать провалом», №6 — брать.
Исходное ревью: `reviews/2026-10-14-tsk992-retrieval-review.md`. Diff: `reviews/2026-10-15-tsk992-minor-5-6.diff`.

## №5 — отказ гейта не «провал»

`retrieval_service._GATE_REJECTION_SQL` исключает из «провала до сдачи»:
- ответ, записанный позже срока попытки (`tasks.time_limit_sec` или `attempts.meta.time_limit` от `created_at`) — гейт 2.3c;
- SA_COM/TBL_COM с пустым комментарием — гейт 2.3f.

Причина отказа в `task_results` не хранится, поэтому распознаётся по данным, без миграции. Известное упрощение: неверный ответ SA_COM с файлом, но без комментария, тоже считается отказом. Это ошибка в безопасную сторону: задание не попадёт на повтор лишний раз. Вложение (2.3e) и пустой TA (2.3g) не нужны: такие задания на повтор не ставятся.

## №6 — повтор не выдаётся за обычную сдачу

| Место | Было | Стало |
|---|---|---|
| История попыток задания (`task_history_service`) | повтор = «Попытка N+1» | `is_retrieval`, номер не растёт; SPW пишет «Повтор» |
| `/me/history` | неверный повтор в фильтре `failed` | `is_retrieval`; в `failed` повтора нет; SPW — «· повтор» |
| Лента преподавателя | «решил задание … (неверно)» | «повторил задание … (неверно)» |
| Сводка занятия, последнее решённое | могло быть повтором | повтор не учитывается |
| `GET /attempts/{id}`, `/finish` | строки повтора в `results` и суммах | исключены |
| Серия, «последняя своя работа» у куратора, напоминание «вернись» | повтор не считался активностью | считается (`own_activity_results_filter`); пробелы и явка по-прежнему без повтора |

## Review-gate

**Решение: ПРИНЯТО.**
- Без таймлимита `make_interval(secs => NULL)` даёт NULL → `IS TRUE` ложно → обычный неверный ответ остаётся провалом.
- Новые поля ответов только добавлены, значения по умолчанию `false` — старые клиенты не ломаются. `openapi.json` пересобирает хук, типы SPW перегенерированы.
- Тесты: tsk992 35/35. Без нового условия тесты №5 падают (2 из 2), контрольный тест «настоящий провал рядом с отказом» проходит. Регресс: попытки, учебный путь, гейты, история, серия, куратор, напоминание, лента, сводка — 417 passed, 1 skipped.

ERRORS.md: не требуется — не инцидент S1/S2 (рубильник выключен, учеников не касалось), вердикт ПРИНЯТО.
