## tsk-472 — порядок глав

**Находка:** `order_number` в `course_parents` присваивается по моменту публикации триггером
`set_course_parent_order_number` (см. коммит `3f5ce72`, tsk-237) — раздел, опубликованный позже,
получает `MAX+1` и уезжает в конец. Системный SQL-скан всей системы (не только курс 826) нашёл ещё
один живой случай — курс 1283 «Тестировщик ПО», Глава 7. Существующий еженедельный чек
`scripts/check_section_order.py` (tsk-237) не видит ни один из двух случаев — блайнд-спот на
`course_uid` формата `-gN` и заголовках «Глава N» (чек ищет только `tema-N`/«Раздел|Тема N»);
заведён отдельный чип на расширение чека.

Сверка с tsk-433 (Волна 2.3, коммит `621074d`, тот же день) — **не связано**: коммит трогает только
права доступа роутов, не логику `order_number`.

**Фикс:** `scripts/tsk472_fix_chapter_order.py` — по одному явному `UPDATE course_parents SET
order_number=...` на курс; триггер `trg_set_course_parent_order_number` каскадно сдвигает соседей.
