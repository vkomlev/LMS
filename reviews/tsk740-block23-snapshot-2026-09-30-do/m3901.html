Вспомни: словари ты разбирал в теме «Работа со словарями в Python», а defaultdict — удобная разновидность словаря, которая сама создаёт пустое значение для нового ключа.

Что такое словарь смежности

Чтобы программа могла ходить по графу, ей нужно быстро отвечать на вопрос: «из вершины X куда можно шагнуть и по какой цене?». Структура, которая отвечает на этот вопрос за один шаг, называется словарём смежности: ключ — номер вершины, значение — список пар «куда, вес».

Для файла-примера из прошлого урока словарь получится такой:

граф = {
  100: [(12, 1.0)],
    6: [(7, 7.0), (1, 1.0)],
    1: [(7, 5.5), (100, 12.0), (4, 2.5)],
    7: [(100, 2.0)],
    4: [(100, 8.0)],
}

Читается так: «из вершины 1 можно попасть в 7 за 5.5, в 100 за 12.0 и в 4 за 2.5». Ключами становятся только те вершины, из которых выходит хотя бы одно ребро. Поэтому вершина 100 в словаре есть — из неё ведёт ребро в 12, — а вершины 12 нет: из неё не выходит ничего. Для вершины-цели это обычное дело: путь В неё есть, а пути ИЗ неё может не быть вовсе.

Чтение файла

from collections import defaultdict

граф = defaultdict(list)
for строка in open('23.txt'):
    части = строка.split()
    if len(части) < 3:
        continue
    откуда, куда, вес = int(части[0]), int(части[1]), float(части[2])
    граф[откуда].append((куда, вес))

Разберём, что здесь важно и почему именно так:

  • split() без аргументов — режет строку по любому количеству пробелов и табуляций сразу. Это ответ на вторую ловушку прошлого урока.
  • Проверка len(части) < 3 пропускает пустые строки в конце файла: без неё программа упадёт на последней строке.
  • float для веса и int для номеров вершин — ответ на третью ловушку.
  • defaultdict(list) избавляет от проверки «а есть ли уже такой ключ»: для нового номера вершины сам создаётся пустой список.

Почему словарь, а не список

Первая мысль школьника — завести список на 1001 элемент и класть рёбра по индексу вершины. Так делать можно, но неудобно по двум причинам. Во-первых, номера вершин разрежены: в файле их 30, а список придётся заводить на 1001 позицию, из которых 971 останется пустой. Во-вторых, для второго вопроса задания (количество путей) нам понадобится перебирать только существующие вершины — по словарю это делается естественно, а по списку пришлось бы отсеивать пустые позиции.

Множество всех вершин, которые вообще встречаются в файле, пригодится дальше, и собрать его удобно сразу:

вершины = set()
for откуда in граф:
    вершины.add(откуда)
    for куда, вес in граф[откуда]:
        вершины.add(куда)

Плоский список рёбер — пригодится дальше

Кроме словаря полезно сохранить рёбра просто списком троек. Словарь удобен, когда мы идём по графу «из вершины к соседям»; список — когда нужно перебрать все рёбра подряд, не спрашивая, откуда мы пришли. Способы проверки ответа, которые разбираются в следующих темах, работают именно со списком.

граф = defaultdict(list)
рёбра = []
for строка in open('23.txt'):
    части = строка.split()
    if len(части) < 3:
        continue
    откуда, куда, вес = int(части[0]), int(части[1]), float(части[2])
    граф[откуда].append((куда, вес))
    рёбра.append((откуда, куда, вес))

Обе структуры набиваются за один проход по файлу: строка читается один раз и кладётся и в словарь, и в список.

Итог:

  • словарь смежности: ключ — вершина, значение — список пар «куда, вес»;
  • файл читается циклом по строкам, split() без аргументов, int для вершин и float для веса;
  • словарь берут вместо списка, потому что номера вершин разрежены и дальше понадобится перебор только существующих вершин;
  • за тот же проход собирают плоский список рёбер — он нужен способам проверки.
