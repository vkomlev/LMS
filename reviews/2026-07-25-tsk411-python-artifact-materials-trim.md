# tsk-411: срез хвоста-артефакта WP-парсинга в материалах курса 88 «Python для ЕГЭ»

## Контекст

Оператор увидел на скриншоте материала 286 «Цикл for в Python» (курс 110) хвостовой блок
«Вопросы» + «Задания для закрепления» со спрятанными под `[spoiler]` решениями — наследие
старого WP-курса. В LMS задание — отдельная сущность `tasks` с автопроверкой, не текст внутри
материала; такой хвост дублирует то, что уже существует как полноценные `tasks`.

Изначально в трекере (tsk-411) было подтверждено 9 материалов по точному маркеру «Задания для
закрепления». Разведка этой сессии показала, что паттерн системный для **всего дерева курса 88**
(подтемы 103–111): почти каждый теоретический материал заканчивается таким хвостом (заголовок
«Вопросы»/«Задания для закрепления/на закрепление/для тренировки/…» + список
`<blockquote class="check">`, иногда со `[spoiler]`). Причина — исходный WP-курс был единым
лендингом с текстовыми заданиями-спойлерами; при переносе в LMS для каждой подтемы завели
полноценные `tasks` (26–57 штук на курс, современные переформулированные условия с автопроверкой),
а текстовый хвост в материалах остался неудалённым.

## Разведка (read-only, MCP `learn_prod_db`)

1. Полное дерево курса 88: подтемы 103–111 (`course_parents`).
2. Найдены 44 материала с признаком `blockquote class="check"` в тексте по всей базе, из них
   **41 в дереве курса 88** (103–111), плюс 3 в курсе 165 «Черепашья графика» (не в дереве 88,
   родитель — «Задание 6 ЕГЭ. Исполнитель Черепаха») и несколько в курсе 326 «Продвинутые темы
   Функций» (родитель — «Основы Python», совсем другое дерево).
3. Для курсов 103–111 подтверждено наличие полноценных `tasks` (26–57 на курс, `is_active=true`,
   современные переформулированные условия с автопроверкой) — дублирование подтверждено на уровне
   курса, как и ожидал тикет.
4. Для курса 165 (материалы 314, 316, 317) — **`tasks` с `course_id=165` НЕТ ни одной строки**.
   Для курса 326 — аналогично 0 задач. Значит хвостовые блоки в этих материалах — единственное
   место, где эти задания вообще существуют в LMS. Это **не дубль, а потенциально утерянный
   контент** — согласно эскалационному правилу тикета, эти материалы **не трогали**, только
   зафиксировали здесь.
5. Курсы `ЕГЭ по информатике` (139, 144–154) — как и предупреждал тикет, `[spoiler]` там в
   основном используется легитимно (решение примера внутри теории), «хвостового» заголовка
   «Задания/Вопросы» перед списком заданий нет — не трогали.

## Алгоритм среза

Скрипт `scripts/trim_wp_artifact_tail_tsk411.py` (на проде, шаблон по образцу
`deactivate_method_posts_tsk362.py`):
1. Разбирает заголовки h2/h3/h4, классифицирует как «хвостовой» (текст матчит
   `Вопрос|Задани|Задач`) или «теоретический».
2. Точка среза — начало первого хвостового заголовка сразу после последнего теоретического
   (или первый `<blockquote class="check">`, если заголовков вообще нет).
3. **Санити-проверка**: если внутри сохраняемой части остаётся ЕЩЁ один более ранний хвостовой
   заголовок или `blockquote class="check"` — материал помечается `IRREGULAR` и НЕ трогается
   (одной точки среза недостаточно, задания вставлены в несколько мест по документу).

## Результат

- **CLEAN — обрезано (40 материалов)**: 206, 208, 214, 215, 221, 222, 226, 227, 229, 239, 240,
  241, 248, 250, 251, 253, 254, 260, 261, 262, 263, 264, 269, 270, 271, 272, 273, 274, 275, 276,
  278, 279, 286, 287, 288, 289, 297, 298, 299, 300 (курсы 103–111). `is_active` не менялся
  (материалы остаются активны, срезан только хвостовой блок в `content->>'text'`), `updated_at`
  обновлён.
- **IRREGULAR — НЕ тронуто, нужен ручной разбор (1 материал)**: id=204 «Числовые операции и
  операторы» (курс 103) — задания вставлены дважды по документу («Задания 2-4» в середине,
  «Задание 5» в конце, между ними ещё теория). Одна точка среза даст неверный результат, требует
  ручной разметки двух отдельных вставок.
- **Не трогали, отдельная категория (не дубль, потенциально утерянный контент)**: материалы 314,
  316, 317 (курс 165 «Черепашья графика») — `tasks` для курса 165 не существует вовсе.
- **Вне охвата тикета, не проверяли на запись**: курс 326 «Продвинутые темы Функций» (родитель
  «Основы Python» — другое дерево курсов, не «Python для ЕГЭ»); курсы ЕГЭ-заданий 139/144-154 —
  `[spoiler]` там легитимен, хвостового блока заданий нет.

## Гарантии протокола `/db-check`

1. Read: полная разведка (см. выше) через `learn_prod_db` (read-only MCP).
2. Dry-run: скрипт по умолчанию печатает план (было/станет, точка среза) и откатывает
   транзакцию — прогонялся дважды, после первого прогона алгоритм доработан (найден и закрыт
   пробел на материале 204 и на случае без теоретических заголовков вроде `elif`/`else`).
3. Бэкап: полный `content` всех 41 материала (40 применённых + 204) до записи —
   [reviews/tsk411-python-materials/2026-07-25-backup-before-trim.json](tsk411-python-materials/2026-07-25-backup-before-trim.json).
4. Применение: транзакция на проде (`5.42.107.253/learn`, роль `lms_prod`) через
   `DBCHECK_OK=1 ... --apply`, скрипт под пользователем `app` на `/opt/lms`.
5. Верификация внутри транзакции: пересчёт длины текста после UPDATE для всех 40 (все совпали).
6. Независимая верификация после commit — отдельный read-only запрос через `learn_prod_db`:
   все 40 материалов, `has_task_block=false` (артефакт исчез), `is_active=true` (материал жив).
7. Живой прогон (аккаунт id 2, `mcp__claude-in-chrome`):
   - `/courses/id-88/material/286` («Цикл for в Python», тот самый материал со скриншота
     оператора) — теория отображается полностью и без обрыва, хвост «Вопросы»/«Задания для
     закрепления» отсутствует.
   - `/courses/id-88/material/298` («Конструкция elif») — аналогично, теория цела, хвост убран.
