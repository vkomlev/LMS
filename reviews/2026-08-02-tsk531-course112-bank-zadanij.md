## Контекст и пересмотр декомпозиции

Задача tsk-531 опиралась на находки review tsk-425. Верификация перед правкой (по
аналогии с tsk-528) вскрыла, что часть предпосылок decomposition не подтверждается
текущим состоянием БД:

- **П.1** («0 HARD/PROJECT в 149-154») — HARD полностью покрыт отдельным осознанным
  кустом «Сложные задания» (id=1378, дети 1379-1403, 952 активных задания, tsk-347).
  Добавлять новые HARD в 149-154 значило бы дублировать существующую архитектуру.
  Реальный пробел — только 0 заданий уровня PROJECT во всём курсе (1748 активных
  заданий). Оператор решил: жанр курса (банк заданий ЕГЭ) не предполагает PROJECT,
  пункт закрыт без правки.
- **П.2 (нога 2, тема 141), П.3 (темы 142, 163), П.6, П.8** — премиса «0 заданий
  уровня EASY» / «нет ручного метода» не подтвердилась: тема 141 — 11 EASY, тема 142 —
  24 EASY (в т.ч. задания на ручной перевод чисел), тема 163 — 8 EASY. Похоже на ошибку
  агента ревью tsk-425 при подсчёте по этим 3 темам (не тайминг — `difficulty_provenance
  .decided_at` части заданий раньше даты ревью). Пропущено, зафиксировано.
- **П.7** — уже закрыт в tsk-528 (материал формулы Шеннона не на своём месте).

## Выполнено

### П.2 (нога 1) — EASY-задания, тема 161 «Формулы и функции в Excel»
Тема имела 0 заданий любой сложности при 8 активных материалах (адресация,
абсолютные ссылки `$`, ВПР, СУММ/СЧЁТЕСЛИ, ПРОМЕЖУТОЧНЫЕ.ИТОГИ). Добавлено 3 задания
SC/EASY (task.id 10010-10012, `external_uid` `lms:c161:easy:0{1,2,3}`), каждое
трассируется к конкретному материалу (329, 333, 332 соответственно). Формулы со
значащими символами (`$`, номер аргумента функции) — тип SC/MC, не SA (assignment-rules
§9 п.5). Порядок верного варианта не на первой позиции ни в одном задании (§4c).

### П.4 (пилот) — hint для HARD-заданий «Сложные», курсы 1398/1399
228 активных заданий в финальном блоке «Сложные» (1398-1403) имели 0% покрытия
`hints_text` (только 53/228 — video hints). Написано и вставлено 16 hint (курсы 1398
«Задание 22», 8 шт.; 1399 «Задание 23», 8 шт.) — метод-ориентированные, без слива
числового ответа (не выводится финальное значение из текста подсказки), без
дословных повторов между заданиями одного набора (варьируется формулировка под
конкретные числа/ограничения условия). ~7% от 228, не полный целевой диапазон
15-20% — продолжение вынесено в [tsk-535](../../Root/tasks/tsk-535-kurs-112-ege-prodolzhit-hint-dlya-hard-zadanij-slozhnye-do-tselevykh-15-20-p-4-tsk-531-kursy-1400-1403.md).

### П.5 (блокер, вынесено) — видео-подсказки, тема 141
Покрытие видео-подсказок 1/15 (7%) подтверждено. Найдено 6 из 14 недостающих заданий
с готовым (дословно совпадающим текстом) видео в ContentBackbone (`tg_parser`,
канал @cyberguru_ege), но ни разу не опубликованным во VK. Штатный CLI-путь публикации
(`vk-upload-one`) поддерживает только источник `vk_importer`, широкие команды
(`vk-upload-many/range/all`) заберут всю очередь канала (тысячи роликов) — риск
случайной публикации посторонних видео. Вынесено в
[tsk-534](../../Root/tasks/tsk-534-kurs-112-ege-opublikovat-vo-vk-6-rolikov-cyberguru-ege-i-privyazat-hints-video-tema-141-p-5-tsk-531.md).
Остальные 8/14 заданий темы 141 не имеют исходника видео в канале вообще.
