# tsk-414 (доделка): реордер по найденным скриншотам писем QA

Оператор прислал повторно ссылки на оба письма (sharing.mail.ru) — в них оказались
встроенные СКРИНШОТЫ навигатора с ручными пометками порядка, которые не сохранились
при первом извлечении текста браузером. Это закрывает два пункта, ранее вынесенных
в письмо как "не смог сделать без скриншота".

## Найдено

- **Письмо ЧАСТЬ 1** (курс 108 «Работа со строками»): скриншот финального вида
  навигатора без пометок — прямой эталон порядка 18 материалов.
- **Письмо ЧАСТЬ 2** (курс 111 «Условные конструкции»): скриншот с рукописными
  номерами 1-25 у каждого пункта текущего списка + отдельно "если расположить по
  порядку" (тот же список, порядок совпадает с сортировкой по номерам).
- Заодно нашлась ТРЕТЬЯ инструкция, которую я раньше не выделил в отдельный пункт:
  "Переместить видео по комментариям после теории по комментариям" (курс 106
  «Первая программа») — текстовая, без картинки, но однозначная по названиям.

## Важно: мой предыдущий фикс курса 108 был НЕПОЛНЫМ

Ранний скрипт `tsk414_reorder_material_264_483_before_string_module.py` (первый
проход этой сессии, без картинки) переставил только материалы 264/483/266
(«Форматирование строк» → перед «Модульstring») — это совпало с частью правильного
порядка, но НЕ учёл ещё 2 перестановки: «Многострочные строки в переменной» (477)
должна идти сразу после «Создание строк» (2-я позиция, не 6-я), и «Срезы в Python»
(474) — сразу после «Срезы и индексы» (7-я позиция, не 20-я). Скрипт
`tsk414_reorder_materials_from_qa_screenshots.py` — полный пересчёт по эталону,
исправляет это.

## Применено (прод, `/db-check`: read → dry-run → транзакция → верификация)

- **Курс 108** (18 материалов): полный порядок восстановлен по скриншоту —
  10 материалов сдвинуты относительно моего раннего неполного фикса.
- **Курс 111** (25 материалов): полный порядок по рукописным номерам — 23 материала
  переставлены (было расставлено почти случайно — правильных позиций осталось 2 из 25).
- **Курс 106**: видео «Комментарии в Python» (id=464) перемещено с `order_position=30`
  на `36` — теперь идёт ПОСЛЕ теории «Комментарии в Python» (id=243, `order_position=35`),
  остальные материалы курса не тронуты (точечный сдвиг, не полный renumber — курс 106
  устроен намного менее регулярно, чем 108/111, полный renumber там рискованнее).

Верификация — независимый read-only запрос после каждого apply: итоговый порядок
материалов 108 и 111 совпадает со скриншотами письма построчно.
