## Часть 2 — синтетическая калибровка (сконструированные примеры)

Раз реальных данных нет, проверяю саму рубрику на контрастных примерах, которые я написал(а) специально для этого — они НЕ из прод-БД.

### Пример А — сознательно «ИИ-стиль»

```python
import turtle


def draw_square(turtle_obj, side_length=50):
    """
    Draws a square using turtle graphics.

    Args:
        turtle_obj: The turtle instance used for drawing.
        side_length: The length of each side of the square in pixels.
    """
    for _ in range(4):
        turtle_obj.forward(side_length)  # move forward by side_length
        turtle_obj.right(90)  # turn right by 90 degrees


my_turtle = turtle.Turtle()
draw_square(my_turtle)
turtle.done()
```

**Вердикт: AI_LIKELY.** Google-style докстринг с секцией `Args:`, построчные англоязычные комментарии, дублирующие очевидное (`# move forward by side_length` к строке `forward(side_length)`), выделение магического числа `50` в именованный параметр с default — избыточная инженерная культура для задачи «нарисовать квадрат» уровня «изучил циклы и функции». Школьник, только осваивающий функции, крайне редко пишет `Args:`-докстринги по конвенции Google Python Style Guide без явного указания это делать.

**Побочная находка:** типичный ИИ-паттерн `if __name__ == "__main__":` в этот пример НЕ включён специально — проверено отдельно (`guard.check_code_is_safe`), что он **автоматически отклоняется песочницей tsk-412** («обращение к имени `__name__` запрещено», dunder-имя под запретом AST-стража). То есть часть наиболее узнаваемых ИИ-идиом уже физически не может дойти до детектора — они бракуются на этапе приёма ответа как `forbidden_construct`, независимо от вопроса авторства. Детектору не нужно ловить эту разновидность вообще.

### Пример Б — сознательно «ученический стиль»

```python
import turtle
t=turtle.Turtle()
for i in range(4):
    if i==2:
        t.color("red")
    t.forward(50)
    t.right(90)
turtle.done()
```

**Вердикт: STUDENT_LIKELY.** Отсутствие пробелов вокруг `=`/`==` (типичная привычка новичка, не проходящая через автоформаттер, которым ИИ-инструменты обычно результат прогоняют), точечное условие `if i == 2` без объяснения назначения (не рефакторено в параметр/константу — сырой экспериментальный код: «раскрашу третью сторону, потому что интересно, как это будет выглядеть»), отсутствие функций и докстрингов. Живой, слегка «грязный» стиль ручной итерации, а не готовый чистовик.
