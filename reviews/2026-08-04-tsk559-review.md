# tsk-559 — review-gate

**Решение: ПРИНЯТО**

## Контекст
ЛК: фильтр активные/все/заблокированные (материалы/задания/люди) + навигация
вперёд-назад в материале/задании/подкурсе методиста. Два репозитория: LMS
(backend) и SPW (frontend), изменения не закоммичены на момент ревью.

## Соответствие целям (Шаг 0 / DRIFT)
- Материалы, задания, люди — реализованы полностью по декомпозиции.
- Курсы — намеренно пропущены: в БД `courses` нет `is_active`/архивации
  (подтверждено грепом `app/models/courses.py`, миграций, схем), оператор
  подтвердил пропуск явным ответом в сессии (не предположение агента).
- Навигация вперёд/назад — материал, задание, подкурс (при ровно одном
  родителе). Корневые курсы — намеренно без нав (нет естественного порядка,
  зафиксировано в декомпозиции и подтверждено). Соответствует ТЗ.

## 12 измерений — коротко
1. **Цели** — покрыты, DRIFT только по курсам, обоснован и подтверждён оператором.
2. **Корректность/edge cases** — first/last/single-item список, multi-parent
   курс (nav скрыта), пустой список под фильтром (текст объясняет, не путает
   с «данных нет вовсе») — всё покрыто тестами и живым прогоном.
3. **Данные/миграции** — нет миграций, используются существующие колонки
   (`tasks.is_active`, `users.blocked_at`).
4. **Безопасность/IDOR** — новые query-параметры не меняют ACL-гейты
   (`assert_course_access`, `_PEOPLE_READ_GATE` не тронуты); новых
   объект-идентификаторов в путях нет.
5. **Тесты** — LMS 9 новых (полный прогон 1622/11, 0 fail); SPW 18 новых +
   точечный фикс 3 существующих файлов, которые сломались из-за нового
   сетевого вызова в `TaskDetail` (полный прогон 988/988, 0 fail). Регресс
   «без параметра = старое поведение» подтверждён явными тестами с обеих
   сторон.
6. **Docs/Config drift** — `openapi.json` перегенерируется pre-commit хуком
   при коммите (стандартный паттерн проекта). Cross-project contract
   (`ContentBackbone/docs/cross-project/contracts/lms-api.md`) обновлён.
7. **Phase integrity** — нет TODO/заглушек. Staged-набор соответствует
   единственной задаче tsk-559 (LMS + SPW часть одной задачи, PROJECTS
   в tsk-559 фронтматтере — LMS и SPW оба).
8. **Goal-level data completeness** — н/п (не про данные/сиды).
9. **Domain model** — н/п.
10. **Date/Time** — не затронуто.
11. **Cross-project memory sync** — `contracts/lms-api.md` обновлён (новая
    запись «Last verified»), `CHANGELOG.md` — новая запись `## 2026-08-04 (6)`
    в начале. `STATE.md` не тронут — фаза/версия не менялись.
12. **Public API Contract Sync** — оба изменённых эндпоинта расширены
    ОПЦИОНАЛЬНЫМ параметром (не breaking), метод/путь/схема ответа не
    менялись. Hardcoded URL-grep не требуется — новых URL нет.

## Живая проверка (обязательна для user-facing UI)
Прогнана на dev-стенде (SPW:3000 + LMS:8000, методист user_id=2,
`node scripts/qa-browse.mjs` + разовый Playwright-скрипт для кликов):
- Фильтр материалов курса 1064: «Выключенные» → 62 строки, «Активные» → 3
  строки — совпадает с прямым запросом к dev-БД.
- Sibling-nav материала: у первого материала курса «Предыдущее» неактивно
  (кнопка, не ссылка), клик «Следующее» реально переводит на соседний id.
- Sibling-nav подкурса: курс 7 (2-й из 5 у родителя 1) — обе кнопки активны,
  ведут на соседние id по `order_number`.
- Люди/blocked: клиентский запрос с `blocked=true` подтверждён перехватом
  сети (корректный URL, роль сохраняется). Фактическую отрисовку в ЭТОМ
  прогоне не удалось увидеть — упёрлись в **не связанный с задачей**
  preexisting баг dev-окружения: Next.js dev-rewrite нормализует
  `/api/v1/users/` (без слеша) → апстрим FastAPI `redirect_slashes` отвечает
  307 с **абсолютным** `Location: http://localhost:8000/...` → CSP
  `connect-src` блокирует кросс-origin переход. Воспроизведено голым `curl`
  без единой строчки кода из этой задачи; в проде отсутствует (там
  `NEXT_PUBLIC_API_URL` абсолютный, Next-прокси не участвует). Не блокер
  PASS — юнит-тесты (18 шт., включая точную сборку URL с `blocked=`) плюс
  LMS-сторонние тесты параметра (9 шт.) закрывают то, что живой прогон не
  смог увидеть визуально из-за инфраструктурной, а не продуктовой причины.

## Находки
Блокирующих нет.

**Улучшение без блокировки:** dev-окружение SPW имеет preexisting
редирект/CSP-нестыковку для любого GET-эндпоинта с trailing slash за
Next.js rewrite-прокси (`/users/`, `/dependencies/` и т.п. — не только тех,
что тронуты в этой задаче). Затрудняет живую проверку people-страниц
локально. Не в объёме tsk-559; кандидат на отдельную мелкую задачу
инфраструктуры dev-стенда SPW.

## Operator handoff
Категория А целиком — рутинная реализация по уже согласованному плану,
все проверки (тесты/lint/type-check/build/живой прогон) выполнены агентом.
Коммит и обновление трекера — тоже категория А (durable-авторизация
`operator-handoff-rules.md`, ревью пройдено).
