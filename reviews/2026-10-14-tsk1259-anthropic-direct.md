# tsk-1259 — прямой API Anthropic вместо CloseRouter: провайдер и стенд Claude 5.5

Дата: 2026-10-14. Задача: `D:\Work\Root\tasks\tsk-1259-…`. Рубильник в коде **выключен**,
прод (`/opt/lms/.env`) не трогали.

## Зачем

CloseRouter подмешивал в `anthropic/*` свою скрытую инструкцию: на одно «Привет» —
269 входных токенов у sonnet-5 и 70 у sonnet-4.6. 10.10 под меткой `openai/gpt-5.5`
он отдал ученику Grok. Оператор положил в `.env` ключ прямого API (`CLAUDE_API_KEY`,
100 $ на счёте). Нужно было проверить, годятся ли модели Claude напрямую для
наставника и для судьи.

**Ловушка, найденная по ходу:** в бою история после вступления начинается с реплики
наставника (`session_service.build_llm_messages`), а Messages API требует первым
сообщение пользователя. Без поправки каждый ход после вступления давал бы 400.
Адаптер подставляет перед ней служебную реплику ученика; боевая сборка для
CloseRouter не менялась.

## Рекомендация (решение оператора)

**Наставник:**
`LLM_TUTOR_MODELS=anthropic-direct/claude-opus-5-5,google/gemini-3.7-flash,google/gemini-3.6-flash`
и `ANTHROPIC_DIRECT_ENABLED=1`.

Opus 5.5 — единственный кандидат, прошедший все четыре правила, и он быстрее нынешней
головы gemini-3.7-flash (4,6–5,4 c против 9,8–10,8 c в спокойные часы). Риск — хвост
под нагрузкой: 8 % ответов дольше 12 c при четырёх параллельных потоках. Такой ответ
бой отрежет, и его подхватит gemini-3.7-flash, но ученик подождёт до 12 c лишних.
Цена: при нынешней нагрузке (десятки ходов в день) ~$0,02 за ход — порядка $1–2 в
месяц, кредита 100 $ хватит надолго.

gpt-5.5 из хвоста убрать: в цепочке он и так третий-четвёртый, а маршрут CloseRouter
под его меткой уже отдавал Grok. Если оператор хочет иметь запас вне CloseRouter —
оставить только gemini (у них маршрут чистый, 2 токена на «Привет»).

**Судья:** `anthropic-direct/claude-haiku-5-5` головой, нынешние gemini за ней. Формат
6/6 на обоих образцах, 3–5 c, ~$0,0004 за разбор (дешевле gemini-3.7-flash через
CloseRouter, ~$0,00045). Слив и поддакивание судье не критерий: с учеником он не
говорит.

**Что нужно от оператора, чтобы включить** (агент не делал):
1. Ключ на сервер: `CLAUDE_API_KEY` в `/opt/lms/.env` (захват `ownership.md` § 5а,
   бэкап рядом). Ключ — секрет оператора, агент его не переносит.
2. Там же `ANTHROPIC_DIRECT_ENABLED=1` и цепочки выше, рестарт `lms`, живая проверка
   наставника (задание 63, «посчитай по шагам») и `llm_usage_event.provider='anthropic-direct'`.
3. Автопополнение выключено: при исчерпании кредита прямой API начнёт отказывать —
   цепочка уйдёт на gemini. Это деградация, а не авария, но стоит следить за балансом.

## Попытка включения 14.10 02:28 — откат

Оператор велел включить. Код выкачен (`cddbf1e`), в `/opt/lms/.env` прописаны ключ,
рубильник и цепочки. Живой вызов (id 2, задание 63, сессия 231): Opus отказал за
41 мс — `403 forbidden: Request not allowed`, ответила запасная gemini-3.7-flash
(наводящий вопрос, без решения). Причина — запрет по стране: сервер в России
(`ipinfo` → RU), Anthropic отвечает ему 403 ещё до проверки ключа. С разрешённого
адреса тот же запрос без ключа даёт 401. Локально стенд работал, потому что машина
оператора выходит в сеть не из России.

`.env` откатан к `.env.bak-tsk1259-direct-20261014`, ключа на сервере не осталось.
Код с выключенным рубильником остаётся на проде, на работу он не влияет.

**Чтобы прямой API заработал на проде, нужен выход в Anthropic не из России** —
например, HTTPS-прокси на зарубежном сервере (у httpx — переменная `HTTPS_PROXY`
или отдельная настройка прокси для этого провайдера). Это решение оператора:
новый сервер, расходы, правила Anthropic о допустимых странах.
