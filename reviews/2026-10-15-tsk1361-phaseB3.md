# tsk-1361 фаза Б3 — причина обязательности и решения преподавателя

**Цель.** Ученик видит, почему элемент необязателен; преподаватель в карточке ученика видит уровень и причину, делает тему необязательной (с масштабом до сохранения), возвращает в обязательные снятое правилом, снимает своё решение. Кнопка «Пропустить» у задания (tsk-919) не тронута — решение оператора 15.10 «развести по уровню».

**LMS:** `RequirementReason`; `requirement_reason` в syllabus-states; `GET /me/requirement`; поля уровня и причины в `ProgressTreeItem`; `GET|PUT|DELETE /teacher/students/{sid}/progress/requirement[/preview]` (ACL `ensure_can_edit_progress`, сервисный токен — 403, решение по необязательному по курсу элементу — 422).
**SPW:** строка причины в оглавлении, на страницах задания и материала (уровень с `/me/requirement`, кнопка пропуска — после ответа), в карточке ученика — причина и три действия. Коммит SPW — с `Hold-For-Operator`.

**Ревью.** Codex LMS — NEEDS_WORK: подтверждено «бесполезное понижение необязательного» → 422; причина только при отличии уровня — защита добавлена; остальное не подтвердилось (данные теста убирает фикстура `graph`). Codex SPW — FAIL (кнопка пропуска по запасному уровню): блокирующее не подтвердилось — сервер проверяет пропуск по уровню курса, запасной уровень не покажет отклоняемую кнопку; мерцание убрано (кнопка после ответа). Независимый агент Claude — ПРИНЯТО; неблокирующее «программа по корню, страница по всем корням» при включённом рубильнике снимается (строки общие для всех корней), расходится только при выключенном.

**Валидация.** LMS: `test_tsk1361_requirement_api.py` + `test_tsk1361_phase_b.py` → 13 passed; затронутые Б3 48 файлов → 607 passed. SPW: `tsc --noEmit` чисто; vitest весь набор → 2214 passed (270 файлов); `student-progress.test.tsx` → 53 passed.
