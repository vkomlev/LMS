# Портреты аудитории: три онбординга (гейт Шага 2)

Калибровка пессимистичная: курс, понятный слабому, понятен и сильному.
Пессимизм выводится из данных, а не выдуман.

## Сегмент A — общий онбординг «С чего начать» (курс 1467)

Аудитория смешанная по решению оператора: школьники 5–11 и взрослые вперемешку.
Берём худший общий знаменатель — двух человек сразу.

| Ось | Что предполагаем |
|---|---|
| Возраст / роль | 13-летний семиклассник-троечник **и** взрослый 45+, который «с компьютером на вы» |
| Опыт онлайн-школ | нулевой. Личный кабинет видел разве что в госуслугах |
| Словарь | не знает в нашем смысле: «кабинет», «материал», «попытка», «наставник», «тариф», «начисление» |
| Чтение | длинный текст не дочитывает; ищет глазами кнопку |
| Страхи | «нажму не туда — сломаю / потеряю попытку / меня отчислят» |
| Машина и среда | школьник — телефон, взрослый — рабочий ноутбук. Второго монитора нет: открыть курс и кабинет рядом не получится |
| Мотивация | пришёл учиться предмету, онбординг воспринимает как препятствие |

**Что это значит для аудита:** каждое слово интерфейса должно быть либо показано
на образе, либо объяснено. Инструкция «открой в соседней вкладке» для телефона —
под подозрением. Абзац без вывода — не дочитан.

## Сегмент B — онбординг ЕГЭ (курс 1474)

| Ось | Что предполагаем |
|---|---|
| Возраст / роль | 10–11 класс, начинает подготовку с нуля или почти |
| Предметный опыт | информатику в школе вели слабо; программировать не умеет |
| Словарь | не знает: «первичный балл», «тестовый балл», «ФИПИ», «КИМ», «демоверсия», «спецификация», «шаблон решения», «исполнитель», «маска подсети», «граф» |
| Что слышал | «информатика сложная», «все списывают шаблоны», «нейросеть решит» |
| Чтение | таблицу читает, если в ней 2–3 столбца; на пятистолбцовой теряет строку |
| Страхи | «я поздно начал», «не успею», «мне не хватит на бюджет» |
| Мотивация | высокая, но хрупкая: пугается цифр вроде «29 первичных» |

## Сегмент C — онбординг ОГЭ (курс 1481)

| Ось | Что предполагаем |
|---|---|
| Возраст / роль | 14–15 лет, 9 класс. Выбрал информатику, потому что «там компьютер» |
| Предметный опыт | школьная информатика в объёме «Word и презентации» |
| Словарь | не знает: «Рособрнадзор», «профильный класс», «КуМир», «исполнитель Робот», «маска файла», «критерии проверки», «первичный балл» |
| Отношение к экзамену | считает, что ОГЭ — «лёгкий тест, там же не ЕГЭ» |
| Чтение | самый нетерпеливый из трёх сегментов; читает выделенное жирным и списки |
| Страхи | скорее беспечность, чем страх: «до июня далеко» |

**Что это значит для аудита:** у сегмента C главный риск не «непонятно», а
«пролистал». Ключевые числа должны попадаться в списках и выделении, а не только
в прозе.
