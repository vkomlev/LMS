## Изменение

Наставник: `z-ai/glm-5.3-flash`, Auto Stable. Судья:
`openai/gpt-6.1-terra` через `provider-28`, затем `openai/gpt-6.1-sol`, Auto Stable.
Подготовка отзывов: Terra, `provider-28`. Прямой Anthropic выключен.
Первоначальный вариант с Sol для отзывов заменён после нативной проверки prod:
таймаут 30 c и аномальный вход 6312 токенов при пороге 2258, отклонённый
проверкой подлинности (содержимое предполагаемой инструкции не получено).
Terra прошла три разных примера; Sol
остаётся резервом только судьи (контрольный вызов 8,126 c).

`providers.request_provider()` выбирает маршрут по точной метке. Общая функция
сборки тела CloseRouter в `client.py` передаёт поле `provider` и для обычного
ответа, и для потока. Штатный месячный стенд берёт тот же маршрут из `providers`,
чтобы повторная проверка Terra не ушла через непригодный Auto.
Настройки аккаунта не изменяются; сообщения прямого API
Anthropic, контракты HTTP LMS, БД, стражи и бюджеты остаются прежними.
Настройки окружения сохраняют приоритет. Исторические записи в контракте
сохранены с датами; действующая редакция — 08.11.2026.

Фоновая проверка цепочек до этого использовала для судьи 1024 токена и не
задавала seed, а для наставника — 32 токена. Проверки приведены к рабочим
параметрам: `JUDGE_MAX_TOKENS=2500`, `seed=42`, `TUTOR_MAX_TOKENS=900`.
Судейская ось месячного стенда также задаёт `seed=42`. Временные пределы
рабочих вызовов и проверки подлинности не изменяются.

1. Проверить точные маршруты, отсутствие переноса закрепления Terra на Sol,

3. Независимое ревью и решение PASS до интеграции. Включить только свои файлы.
4. На prod сохранить `.env` с исходными правами. Сначала штатно выкатить новый

5. Проверить `/health`, среду процесса, боевой клиент на синтетических сообщениях
   наставника, судьи и подготовки отзыва, баланс до/после и ошибки сервиса.
   Реальные учебные работы/попытки не создавать. Отчёт — `docs/qa/`.

## Известные ограничения

У наставника одна одобренная модель; добавление резерва требует нового стенда
и отдельного решения. Видимая медиана первого текста 6,86 c при цели 5 c и
бюджете 12 c. При 429 остывает весь CloseRouter, запасная модель того же
провайдера не вызывается. Auto Stable выбирает поставщика конкретной модели,
а не оптимальную модель; отказ от выбора модели каталогом не подтверждён.
Sol остаётся в согласованной судейской цепочке с действующими стражами, но
в ранних контролях были отказы на первом образце, несмотря на успех второго.
Заключительный штатный тик 19:36–19:39 проверил обеих судей и роль наставника
без тревог: функциональная приёмка PASS; устойчивость Sol остаётся риском.
Новый резерв или исключение Sol — отдельное решение оператора.
Судейский стенд не измеряет качество отзывов. Поэтому для этой роли отдельно
проверены штатный `write_llm_draft`, предел 700 токенов и содержательное
соответствие рубрике, без готового решения и похвалы невыполненным критериям.
