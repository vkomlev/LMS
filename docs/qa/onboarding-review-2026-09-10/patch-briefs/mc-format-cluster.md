## Решение — предложение, не мандат

Два независимых рычага, можно применять по отдельности к разным заданиям:

1. **Перевести в SC**, если у задания есть один явно доминирующий признак
   (например id=10202: правильных 2 из 4, но можно переформулировать как
   «какое из этих утверждений верно» и оставить одно самое характерное).
   Плюс: сразу снимает весь класс проблемы. Минус: теряется часть проверки
   (остальные верные/неверные утверждения перестают проверяться).
2. **Включить partial scoring для MC** (если поддерживается — сверить
   схему `solution_rules.scoring_mode` для типа MC, возможно потребует
   доработки backend, отдельная оценка объёма). Плюс: сохраняет полноту
   проверки. Минус: не про эту задачу — это уже задача разработки.

Приоритет 10177 — отдельный (см. свой наряд), он и без формата MC
проблемный по содержанию.

## Не менять

- Формулировки стемов («Отметь всё, что верно») — они корректны и
  однозначны, дефект не в тексте.
- Сами материалы — содержание не требует правки.
