## 3. Выводы

1. **Обе модели боевого наставника через CloseRouter вечером 20.10 подменялись массово.** gemini-3.7: 74 из 107 ходов во втором проходе пришли как `msg_<hex>` (Claude/прочее под меткой Google). gpt-5.5: новый вид id `chatcmpl-cache-<hex>` и 4390 входных токенов на «Привет» — тот самый маршрут с инструкцией Codex из tsk-1376. Клиент такие ответы честно отбраковывает, но ученик в эти часы получает молчание/«преподаватель». Новый вид id `chatcmpl-cache-` в правилах отпечатков стоит явно отнести к подмене (сейчас отбраковывается и так).
2. **Чистых и одновременно быстрых моделей на CloseRouter нет.** deepseek-v4.1-flash и gpt-6-luna подлинные и держат роль, но deepseek теряет треть ответов (сбой upstream), а gpt-6-luna медленная (медиана 15,9 c, 69 % > 12 c). qwen3.8-flash — с подмешанной инструкцией и самая медленная.
3. **Единственный маршрут, прошедший все четыре оси дважды, — Opus 5.5 напрямую**: подлинен, роль 8/8, поддакивания на глаз нет (сходится с 14.10), 107/107 ответов, первый кусок 8 c / p90 10–12 c. Но с RU-сервера он недоступен (403) и в ~40–70 раз дороже.
4. Судья: формат держат все; текущая luna вылезает за бюджет 30 c в обоих проходах. Лучший кандидат на звено — `gemini-3.8-flash` (18–19 c, худший < 30 c оба раза), но в наставнике она таймаутит, и подлинность в судейском стенде не проверяется — перед вводом нужна проба id.
5. Ограничения: оба прохода вечерние; поддакивание оценивал судья-модель (фильтр, не вердикт), глазами прочитаны только флаги; 152-ФЗ по зарубежным маршрутам не разбирался (нужен `/lawyer`).

## 4. Рекомендация (решение за оператором)

- **Стратегически:** выбрать маршрут без посредника-подменщика. Варианты по убыванию качества:
  **A.** Выход сервера к Anthropic через зарубежный узел (VPS/прокси вне РФ) + уже готовый провайдер `anthropic-direct` (рубильник выключен): наставник `claude-opus-5-5`, затем CloseRouter-звенья как запасные. Лучшее качество, ~$90 на 1000 разговоров; вопрос 152-ФЗ (трансграничная передача) — через `/lawyer`.
  **B.** Российский вендор с договором (Yandex AI Studio: Alice AI LLM / DeepSeek V4.1 / Qwen; или GigaChat) — 152-ФЗ закрыт, подмены нет по построению; **не проверено стендом** — нужен ключ.
  **C.** Остаться на CloseRouter — только с третьим звеном и признаком подмены по входным токенам; качество маршрута не контролируем.
- **Тактически, пока решается (на CloseRouter):** наставнику добавить третьим звеном `openai/gpt-6-luna` (чистая, роль 8/8) — медленно, но лучше молчания; судье заменить `gpt-5.6-luna` на `google/gemini-3.8-flash` после пробы id. Дневной замер — до изменения цепочки.

## 5. Чего не хватает оператору (ветвь Б)

1. Ключ **Yandex AI Studio** (сервисный аккаунт + каталог, юрлицо/ИП) — для стенда варианта B.
2. Ключ **GigaChat API** (бесплатный режим для проверки) — второй российский кандидат.
3. Для варианта A: зарубежный узел для выхода к `api.anthropic.com` с сервера (или решение «не делаем», как 14.10).
4. Ключ любого РФ-посредника с явным маршрутом (ProxyAPI.ru) — если нужна проверка Gemini/GPT вне CloseRouter.
5. Пополнить баланс CloseRouter (на 19.10 было $1,72; стенд 20.10 тоже его тратил).
6. Разбор 152-ФЗ для зарубежных маршрутов (`/lawyer`).

Сырые отчёты стенда — в скратчпаде сессии (не в репозитории).
