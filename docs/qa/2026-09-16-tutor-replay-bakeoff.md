Вижу проблему в строке `print()` — там пропущена запятая между частями текста.

**Что не так:**
```python

```

Между `"!"` и `"Тебе уже"` стоят две кавычки подряд (`""`), но нет запятой. Python воспринимает это как конкатенацию строковых литералов (склеивание), что работает, но создаёт текст без пробела: `"!Тебе уже"`.

**Правильный вариант:**
```python
print("Привет,", name, "!", "Тебе уже", old, "лет!")
```

Или компактнее через f-строку:
```python
print(f"Привет, {name}! Тебе уже {old} лет!")
```

**Как составлять строку вывода через запятые:**
1. Открываешь `print(`
2. Пишешь первую часть в кавычках: `"Привет, "`
3. Ставишь **запятую** `,`
4. Добавляешь переменную: `name`
5. Снова **запятая** `,`
6. Следующая часть: `"!"`
7. **Запятая** `,`
8. И так далее: `"Тебе уже"`, `,`, `old`, `,`, `"лет!"`
9. Закрываешь скобку: `)`

Главное правило: **между каждым элементом (строка или переменная) ставь запятую**. Python сам добавит пробелы при выводе.
