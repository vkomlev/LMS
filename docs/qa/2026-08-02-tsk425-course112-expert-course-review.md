## Общий грейд: **F**

**Определили грейд формально по правилу свёртки report-format.md: «F —
хотя бы один P0 по опорному критерию (К1/К3/К4), ИЛИ два+ P0 суммарно».**
Опорные критерии (К1 выравнивание, К3 полнота, К4 практика/освоение) сами
по себе держатся на уровне ОГОВОРКИ — ни один из них не провалился. Но во
всём курсе подтверждено **2 находки P0** (обе — темы 144-146/147, пакет 4,
order_number 17-20): К2 (последовательность, термин-стена Python) и К8
(доступность/UDL, нет альтернативного канала для не-Python-сегмента ЦА).
Правило «два+ P0 суммарно» формально требует F независимо от того, что
оба P0 — по неопорным критериям.

**Честная оговорка к грейду, чтобы не создавать ложного впечатления
«курс сломан целиком»:** 18 из 28 тем куста (пакеты 1-3, задания КИМ 1-15)
сами по себе не содержат ни одного P0 и в изоляции тянут на грейд **C**
(добротный, но требующий доработки по опорным критериям — см. ниже). Все
2 подтверждённых P0 сконцентрированы в 3-4 темах (144, 145, 146,
частично 147) и происходят из ОДНОЙ структурной причины (см. RC1 в
наивном отчёте) — устранение одной причины (вводный Python-модуль перед
order_number=17) закрывает оба P0 одновременно. Это низкая по объёму, но
высокая по грейд-эффекту правка.

## Карта покрытия цели

- **Заявленная цель курса:** подготовка ко всему ЕГЭ по информатике (все
  27 типов заданий КИМ), ЦА — старшеклассники 10-11 класса разного уровня,
  включая учеников без Python-трека.
- **Что курс реально даёт:** полное формальное покрытие всех 27 номеров
  КИМ (28 листьев дерева, ни одного пропущенного задания), 796 активных
  заданий на реальных вариантах экзамена, качественные пошаговые разборы
  почти везде для тем 1-15, аутентичное оценивание.
- **Разрыв 1 (главный, ведёт к F):** для сегмента ЦА без Python-трека курс
  не даёт входа в программирование именно там, где оно впервые обязательно
  (order_number=17, задание 16) — далее весь курс (задания 16-27, больше
  трети дерева) для этого сегмента ЦА фактически недоступен тем путём,
  который даёт материал.
- **Разрыв 2:** банк заданий не выходит на верхний ярус сложности
  (HARD/PROJECT) ни в одной из 28 тем — ученик, прошедший курс целиком,
  ни разу не тренируется на предельном для темы уровне.
- **Разрыв 3:** формирующая обратная связь (подсказки/объяснения) фактически
  отсутствует по всему курсу — ученик получает только «верно/неверно».
- **Разрыв 4:** локальные дыры полноты — 2 темы без своей теории (23, 26),
  2 подлинно ценных материала скрыты (408, 410), 1 материал фактически
  пуст при этом ключевой (434, подсчёт точек для задания 6).
