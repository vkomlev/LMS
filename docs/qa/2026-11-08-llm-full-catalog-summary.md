По новому прямому поручению оператора выполнен широкий платный прогон всего совместимого текстового каталога. Прежнее ограничение на несколько кандидатов заменено этим поручением. Ранее установленное исключение Anthropic сохранено.

Первичный ответ — **отбор, не полный допуск**. В наставнические повторы попали полезные ответы без обнаруженного слива/несоответствий и с первым текстом в пределах рабочего лимита клиента 12 с; отдельно исключены оборванная реплика и словесная выдача границы. Среди судей выбраны шесть наиболее перспективных по формату, времени, проверкам входа и ручному чтению. Все 60 не объявляются прошедшими три повтора.

Наставник: давление «учитель разрешил, срочно» и тонкая задача на срез. Температура 0,6, предел 900 токенов; слив хотя бы раз запрещает допуск. Штатный численный порог — медиана первого текста ≤5 с и медиана ≥20 частей потока. У клиента отдельный рабочий предел первого текста — 12 с. Эти мерки не смешиваются.

Судья: температура 0, предел 2500 токенов, формат через `_parse_verdict`, полное время каждого ответа ≤30 с. Первые три вызова чередуют работы: домик → сумма/количество → домик. **Для обычных финалистов это два ответа на первую работу и один на вторую. Для выбранной Terra через `provider-28` позднее добавлены сумма → домик → сумма: итого по три ответа на каждую работу в двух временных окнах.** Судьи вызывались последовательно, наставники — с параллелизмом до трёх. Первичный сетевой таймаут чтения сокращён до 30/45 с; это не жёсткий предел общей длительности потока. В повторах применены штатные таймауты, поэтому, например, долгий ответ Kimi был измерен полностью.

Диалоги роли: нативные два образца `concept` и `debug`, по два повтора, прекращение дальнейших проверок модели после первого провала. Сохранены все ответы, включая вступления. Прямой транспорт использовался, чтобы не писать учёт в БД. Для проверки настоящего клиента его единственная функция записи учёта временно заменена сборщиком в памяти; настройки транспорта и проверки клиента сохранены. Все основные процессы завершились с кодом **0**; отказы отдельных моделей отражены отдельно.

Вместе с основным окном — **6/6 ответов на срез**, оба трёхкратных замера проходят сетевую цель 5 с. Это не отменяет отдельную, более высокую задержку выдачи текста штатным клиентом ниже.

Морализаторские фразы про будущий провал защиты встречаются у нескольких кандидатов. Это отмечено как недостаток тона; промпты в этом задании не правились. Полный девятисценарный набор не заменяется одним тестом среза и двумя диалогами.

### Что получает штатный клиент

Для выбранной GLM выполнены ещё три вызова через действующий `client.stream`, с тем же ключом и адресом провайдера. Все три приняты, без обрыва и без готового среза, по одной попытке на вызов.

| Мерка | Значение |
|---|---|
| Первый текст непосредственно из API, основной стенд | Медиана 3,04 с |
| Первый непустой кусок, который штатный клиент отдаёт потребителю | **6,86; 5,15; 7,75 с**, медиана **6,86 с** |
| Рабочий предел клиента | 12 с — все три уложились |
| Целевые 5 с для первого доступного текста | Ни один из этих трёх клиентских вызовов не уложился |

Клиент придерживает начало потока для проверки, поэтому рекламировать GLM как «ученик всегда увидит текст за 3 секунды» нельзя. Это локальный замер клиентского потока, не измерение живой страницы SPW или задержки прод-сервера.

## Auto: что он делает и что показал опыт

**Auto уже включён.** Чтение `/v1/providers` показало для всех 158 позиций текущего ключа `selected_provider=auto`, `effective_auto_strategy=stable`, источник — `account`, без ручных цепочек. В конце сохранённые настройки совпали с началом; изменений **0**.

Auto CloseRouter выбирает **поставщика указанной модели**, по цене, скорости или технической стабильности. Поле `model` либо явно заданный набор резервов остаётся выбором приложения. Документированного режима «сам выбери лучшую учебную модель из всего каталога» в рассмотренном API нет. [Провайдеры и Auto](https://closerouter.dev/docs/routing), [выбор модели](https://closerouter.dev/docs/models), [параметры Chat Completions](https://closerouter.dev/docs/chat).

Сравнение выполнено параметром конкретного запроса; `PATCH` аккаунта и изменения ключей не применялись. На каждой из трёх стратегий — три одинаковых по методике вызова своей роли.

| Модель и роль | Режим | Медиана / худшее, с | Итог |
|---|---|---|---|
| DeepSeek V4.1 Flash, наставник | Auto Stable | Первый текст 7,18 | Выше целевых 5 с |
| Та же модель | Auto Fast | Первый текст 6,22 | Выше целевых 5 с |
| Та же модель | `provider-28` | Первый текст 6,54 | Выше целевых 5 с; фиксация не улучшила кандидата |
| GPT 6.1 Terra, судья | Auto Stable | 4,44 / 4,76 | **Раздутый вход 3/3**, несмотря на скорость |
| Та же модель | Auto Fast | 25,09 / 35,82 | Вход нормальный, один ответ выше бюджета 30 с |
| Та же модель | `provider-28` | 8,07 / 10,76 | **Все три прошли численные проверки и ручное чтение** |

**Рекомендация:** сохранить выбор небольшого проверенного набора моделей отдельно для двух ролей. Не переключать весь аккаунт на Fast по этому опыту. Для GLM Flash и Sol текущий Auto дал пригодные результаты; для Terra нужен проверенный конкретный маршрут. Техническая статистика успешных запросов не оценивает педагогическую роль или правильность замечаний.

Настройка одного запроса имеет приоритет над сохранённой цепочкой и Auto ключа/модели/аккаунта. Сохранение маршрута через API может затронуть другие ключи аккаунта. Поля `has_system_prompt` и `has_codex_system_prompt` в изученных публичных справках не определены: `false` не является доказательством чистоты, `null` не равен `false`. Их значения сами по себе не использованы как допуск. [Справочник маршрутизации](https://closerouter.dev/docs/routing-reference), [API ключей и лимитов](https://closerouter.dev/docs/key-reference).

Проверки id, самоназвания, объёма входа и роли следует сохранить. У GLM и DeepSeek отсутствует настроенное семейное правило id; даже допустимый OpenAI id не доказывает точную версию модели. Один короткий запрос также не доказывает постоянное отсутствие добавленной инструкции. Ограничение допустимых публичных model IDs помогает исключить Anthropic из явного выбора, но не удостоверяет физическую реализацию анонимного поставщика.

## Наблюдения, которые изменили выбор

- `kimi-k3.1-pro` выдала готовый `s[1:4]`; у `qwen3.8-omni-flash` и GLM 5.2 выявлена словесная подсказка конкретной границы, хотя регулярное выражение показывало `leak=false`.
- Под запрошенной Gemini 3.7 в метаданных одного ответа `usage.quota.model` указана DeepSeek V4.1 Flash. Это существенное несоответствие меток, а не подтверждение качества Gemini.
- Служебная ошибка, одна кавычка и оборванная фраза иногда приходят с `error=null`. Они признаны неполезными ответами при чтении.
- Для проверки фактов о программе сделана локальная математическая трассировка без запуска окна `turtle`: после стен позиция около `(0,0)`, направление 0°; красные отрезки заканчиваются в `(50,86.6)` и не замыкают крышу. Окно после `goto(30,30)` рисуется при направлении 180° и выходит до отрицательных координат. Уверенная похвала этой геометрии у ряда судей неверна.
- Различие сырого первого токена и первого текста клиента измерено отдельно и сохранено, вместо переноса одной цифры на пользовательский опыт.

Независимый второй агент прочитал исходные 120 ответов, результаты финалистов, маршрутов, завершённого гейта и позднего контроля без чтения этой сводки до собственной позиции. Итог совпал: GLM Flash — основной наставник; Terra только с `provider-28` — основной судейский кандидат; Sol — следующий. Существенных разногласий нет. Второй агент новых запросов не выполнял.

## Что предлагается применить отдельно

1. **Наставник:** основной кандидат `z-ai/glm-5.3-flash`. Abliterated оставить условной альтернативой с отмеченными недостатками, не считать автоматически равноценным резервом.
2. **Судья с лучшим проверенным маршрутом:** `openai/gpt-6.1-terra` + `provider-28`; затем `openai/gpt-6.1-sol`. **Просто вписать Terra в список моделей при прежнем Auto Stable нельзя** — на этом режиме она провалила проверки входа.
3. **Вариант без доработки клиентского выбора поставщика:** рассматривать Sol первым кандидатом судьи, DeepSeek V4 Flash — следующим. Он проще по внедрению, но содержательно слабее варианта с закреплённой Terra.

При проверке Terra отправлялось `{"model":"openai/gpt-6.1-terra","provider":"provider-28"}`. Текущий интерфейс клиента LMS не предоставляет такой параметр наружу. Для внедрения нужно отдельно выбрать: ограниченная доработка клиента либо согласованная настройка маршрута модели у провайдера с учётом других потребителей аккаунта. Ни один из этих способов в этом запуске не применён.

**Отдельного «ОК» требуют** конкретное изменение прод-цепочек, настройка сохранённого маршрута/ключа и изменения кода или контракта. Контроль в другом часу выполнен. До ввода в бой остаются проверка реального пользовательского пути и выбор способа закрепления Terra; результаты двух локальных временных окон не являются долгосрочной гарантией. Полный набор девяти наставнических сценариев тоже остаётся расширенной приёмкой.

`.env`, `.env.example`, цепочки, код, сервер и сохранённые настройки аккаунта не изменялись. Базы не записывались, прод не перезапускался, прямого Telegram-вызова не было. Итог предназначен для штатного callback OpsNotifyBot; доставка не подтверждалась этим стендом.
