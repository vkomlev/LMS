## Новые находки (не пересекаются с tsk-155/392/395/396)

### [P1][W4] Нет блока «Что нужно перед стартом» на входе курса
Место: L1-навигатор, `https://victor-komlev.ru/oge-po-informatike-navigator-po-kursu/`.
Курс требует несколько внешних программ: архиватор (задания 11-13, файлы
`.rar`, подтверждено SQL — 31/34, 30/34, 25/28 задач соответственно), среду
КуМир (задание 15), программу для `.ods`-таблиц (задание 14). Ни один из этих
инструментов не анонсирован на входе — девятиклассник узнаёт о необходимости
архиватора/КуМир только зайдя внутрь соответствующего задания. Это близкий
класс к finding tsk-155 №2 (тот же паттерн «нет install-инструкции» на курсе
Информатика 5-11), но новая конкретная точка (отсутствие блока на L1, а не
внутри уроков 11-15, где сейчас инструкция уже есть — см. ниже).

### [P2][W6] Шаблонный блок «Как скачать и распаковать архив» не соответствует
факту в заданиях 14 и 15
Подтверждено фактом (SQL по `task_content`): курс 1179 (задание 14) — 0 из 28
активных задач используют `.rar`, все 25 внешних файлов — прямые `.ods`; курс
1180 (задание 15) — 0 из 29, все 25 внешних файлов — прямые `.svg`. Тем не
менее живой рендер обеих L3-страниц показывает подробную инструкцию «Кликни по
ссылке на архив (обычно .rar) → правой кнопкой → Извлечь всё» — шаг, которого
для этих двух заданий не существует. Для заданий 11-13 (курсы 1163/1164/1178)
та же инструкция фактически верна (файлы реально `.rar`). Похоже на шаблон
публикатора, вставляемый по признаку «у банка задания есть внешний файл», без
проверки расширения. Не блокирует (прямая ссылка всё равно открывается), но
создаёт трение и недоверие к остальным шагам инструкции у наивного ученика.

### [P2][W8] Отсылка к прошлой теме — текст, не гиперссылка
Место: материал `authored:oge-informatika:zadanie-14#m2` («Что нужно знать»).
Текст «курс «Информатика 5-11»: Табличный процессор и Инструменты анализа
данных» упомянут по имени без `<a href>` (проверено по сырому HTML материала),
хотя узлы 1043/1044/1045 реально прикреплены как дочерние в LMS-графе курса
1179 (подтверждено `course_parents`). Ученик, забывший формулы, не может кликом
перейти к нужному уроку.

### [P3][W6] Нет скриншота интерфейса КуМир (частичное продолжение старой находки)
tsk-155 finding №3 («задание 15 не объясняет внешний инструмент») сейчас
**в основном закрыта**: на живой странице задания 15 появился абзац «Что такое
КуМир» с определением и прямой ссылкой на установку (`niisi.ru/kumir`).
Оставшаяся часть находки — скриншот интерфейса среды — по-прежнему отсутствует.
Понижаю приоритет P1→P3, т.к. текст+видео (2 видеоразбора) закрывают понимание
достаточно.

## Что уже хорошо
- Теория режется на короткие H2-атомы (150-250 слов) с ASCII-схемой/формулой и
  числовым примером сразу следом — устойчивый паттерн по всей проверенной
  выборке, снижает когнитивную нагрузку для слабого девятиклассника.
- Задания идут не только «посчитай», но и «разбери чужую ошибку» (SC-вопрос
  «в чём ошибка ученика», задание 1) — учит распознавать типовые ловушки.
- Структура «один лист = одна тема = свой банк» не воспроизводит известный
  повтор-дефект «все пункты ❓/💻 ведут на один и тот же URL без якоря»
  (Информатика 5-11): в навигаторе ОГЭ на каждый раздел ❓/💻 — один
  осмысленный пункт, а не список из десятков с общим адресом.
- disclaimer «часть 2, ручная проверка» звучит последовательно на всех
  проверенных страницах (14/15/16), в отличие от состояния на момент tsk-155
  (finding №4, «непоследовательно») — судя по всему, доработки tsk-395/396
  заодно выровняли и текст.
