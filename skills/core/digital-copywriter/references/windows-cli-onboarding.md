# Локальный CLI на Windows: проверка учебных инструкций

Перед первой командой указать оболочку и версию. Проверять механизм, а не список
названий: запуск `.ps1`, создание файла, переменные окружения, пути и вывод ОС.

## Запуск скрипта
Если фактически возник `PSSecurityException`, проверить `Get-ExecutionPolicy -List`.
Не утверждать, что любая Windows обязательно блокирует скрипты. Для npm доступен
`npm.cmd`; для Python venv можно запускать `.venv\Scripts\python.exe` без активации.
Если требуется именно скрипт, объяснить выбор временного `-Scope Process RemoteSigned`
или постоянного пользовательского `-Scope CurrentUser RemoteSigned`; корпоративную
политику не обходить. Execution Policy не является полной границей безопасности.
Постоянное изменение настроек не включать автоматически в безобидный пример установки.

## Создание файлов и окружение
- `echo … > file` в Windows PowerShell 5.1 создаёт UTF-16LE с BOM; PowerShell 7
  использует другие значения по умолчанию. Для `.env` показывать явный UTF-8 без BOM
  через редактор или `[IO.File]::WriteAllText(path, text, [Text.UTF8Encoding]::new($false))`.
  В учебном примере только фиктивный токен; настоящий не печатать и не коммитить.
- `$env:NAME="значение"` действует в текущей сессии. `setx NAME "значение"` использует
  пробел, а не `=` и применяется к новым процессам. Не сохранять секреты через `setx`.
- Если `python` открывает Microsoft Store, проверить установленный интерпретатор и
  доступность `py`; не обещать, что `py` имеется на любом компьютере.
- `.env` создавать через редактор или `New-Item -ItemType File -Path .env`;
  не объявлять запрет имени с точкой свойством всех современных версий Проводника.
- Вывод путей и скриншоты соответствуют ОС ученика; перезапуск терминала может
  потребоваться после изменения PATH.

## Проверка результата
Каждый шаг содержит ожидаемый признак успеха и расшифровку типичной ошибки:
«не распознано» → проверить установку/PATH/окружение; блокировка `.ps1` → политику.
Новичку дать последовательность кликов до первого результата, включая онлайн-песочницу,
скачивание/распаковку архива и первый запуск. Точный интерфейс — скриншот, не декор.
