После этого урока ты сможешь: собрать свою первую программу задания 23 целиком — от скачанного файла до числа, которое вписывается в поле «Ответ», — и разобрать три ошибки, на которых спотыкаются в первый раз.

Вспомни: Python на компьютер ставили в теме «Как установить Python». Если он уже стоит, ничего доустанавливать для задания 23 не нужно — всё, что понадобится (functools, collections), входит в сам Python.

Шаг 1. Скачать файл — и не потерять его

В карточке задания есть ссылка «Файл к заданию», подписанная понятным именем вроде 23_s1.txt. Но сохранится файл под другим именем: длинной строкой из букв и цифр, например 372ccd2454e1e4b64f4eade63994d8c830c7ff9444ba01635fd97cd35c5a4129.txt. Это не ошибка — так устроено хранилище: имя файла является его «отпечатком», и у каждого задания он свой.

Отсюда первое, что нужно решить: под каким именем программа будет его искать. Проще всего сразу переименовать скачанный файл в короткое 23.txt — тогда код из уроков заработает как есть. Второй вариант — оставить имя как есть и вписать его в программу целиком, в кавычках.

Шаг 2. Положить файл рядом с программой

Строка open('23.txt') ищет файл в той же папке, где лежит сама программа, а не в «Загрузках». Поэтому файл надо перенести туда, где вы сохраните свой .py-файл. Если этого не сделать, программа остановится с ошибкой FileNotFoundError — это буквально «файл не найден», а не поломка кода.

Шаг 3. Программа целиком

Чтение файла ты уже разобрал в прошлом уроке. Функцию поиска пути подробно разберём в следующей теме — сейчас задача другая: убедиться, что программа у тебя вообще запускается и выдаёт число. Поэтому возьми её целиком, как готовую заготовку. Здесь ищется кратчайший путь из вершины 691 в вершину 893 — номера берутся из условия конкретного задания и меняются под него:

from collections import defaultdict
from functools import cache

# 1. читаем файл и строим словарь смежности
граф = defaultdict(list)
for строка in open('23.txt'):
    части = строка.split()
    if len(части) < 3:
        continue
    откуда, куда, вес = int(части[0]), int(части[1]), float(части[2])
    граф[откуда].append((куда, вес))

# 2. функция: длина лучшего пути из вершины до финиша
@cache
def лучший(вершина, финиш):
    if вершина == финиш:
        return 0.0
    ответ = float('inf')
    for сосед, вес in граф[вершина]:
        ответ = min(ответ, вес + лучший(сосед, финиш))
    return ответ

# 3. номера вершин из условия задания — и ответ, целая часть
print(int(лучший(691, 893)))

Программа запускается двумя способами. Первый: открыть её в IDLE (он ставится вместе с Python) — меню «File → New File», вставить код, сохранить рядом с файлом задания и нажать F5. Второй: сохранить как reshenie.py и в командной строке, находясь в той же папке, выполнить python reshenie.py.

Шаг 4. Что должно получиться

Признак успеха простой: в окне вывода появляется одно целое число без точки — например 784. Именно оно вписывается в поле «Ответ». Программу и есть тот самый «ход решения», который прикладывается в поле «Комментарий».

Три ошибки первого запуска

FileNotFoundError: [Errno 2] No such file or directory: '23.txt'
    -> файл лежит не рядом с программой либо называется иначе
       (проверьте: не осталось ли длинное имя-отпечаток)

OverflowError: cannot convert float infinity to integer
    -> функция вернула бесконечность: из старта до финиша пути не нашлось.
       Почти всегда это перепутанные номера: старт и финиш поменяны местами
       или номер переписан из условия с опечаткой

вывод вида 784.0 или 784.5
    -> забыт int(...) вокруг ответа: задание просит целую часть

Отдельно про четвёртый случай, самый неприятный: программа отработала и напечатала число, но оно неверное. Тогда ошибка не в запуске, а в решении — и здесь помогает приём из темы про кратчайший путь: посчитать то же самое вторым способом (Дейкстрой или Беллманом-Фордом) и сравнить.

Итог:

  • скачанный файл приходит с длинным именем-отпечатком — его переименовывают в 23.txt либо вписывают имя целиком в программу;
  • файл кладут в ту же папку, где лежит .py-файл, иначе FileNotFoundError;
  • программа собирается из трёх частей: чтение файла, функция поиска, печать ответа; как устроена функция — в следующей теме;
  • напечаталась ошибка про бесконечность — пути не нашлось, проверьте номера старта и финиша;
  • признак успеха — одно целое число в выводе, оно же идёт в поле «Ответ», а сама программа — в «Комментарий»;
  • число напечаталось, но неверное — это уже не про запуск, а про решение: проверяют вторым способом.
